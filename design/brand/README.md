# NutriTime Logo 资源

本目录保存已经确认的“叶芯时环”标志。手机端与 Wear OS 手表端共用同一套轮廓，避免不同设备显示成两个品牌。

## 品牌颜色

- 圆环绿：`#63D18A`，用于应用图标和手表图标背景，与 App 进行中圆环一致。
- 深墨绿：`#426561`，用于浅色背景上的标志和字标。
- 珊瑚红：`#FF786A`，用于圆环上的开始时间点。
- 白色：`#FFFFFF`，用于绿色背景上的计时圆环与叶片。
- 启动绿：`#1ACE87`，只用于手机冷启动背景，来自已确认参考应用的启动页。

## 文件类型

- `source/`：用户确认的视觉稿，只用于追溯设计来源。
- `masters/`：1024 像素母版、透明标志、单色标志和横向字标。
- `exports/app/`：手机应用图标常用尺寸。
- `exports/watch/`：圆形手表图标常用尺寸，圆外保持透明。
- `exports/mark/`：浅色背景使用的深墨绿透明标志，包含 24 像素小尺寸。

`generate_logo_assets.py` 会从确认稿提取轮廓并重新输出纯色资源。运行脚本需要 Python 和 Pillow（负责读取、缩放及保存图片），不会修改业务代码。

## 使用规则

- 手机和手表启动器优先使用圆环绿背景的彩色版。
- 系统主题图标使用单色版，由系统决定最终显示颜色。
- 浅色页面或宣传图使用深墨绿透明版。
- 手机启动页使用白色竖向标志与名称，背景使用启动绿；这样系统缩放后仍能同时看清图形和品牌名。
- 不要拉伸、旋转或单独移动珊瑚色圆点；这些变化会破坏“开始计时”的含义。
